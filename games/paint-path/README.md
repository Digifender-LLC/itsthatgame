# Paint Path (`paint-path`)

Premium one-stroke grid puzzle for ItsThatGame (roadmap M3). Implements `FR-GAME-1`,
`FR-GAME-2` against the game contract in `docs/design/LLD.md` §1.

## Mechanic

A start cell (star) is marked on a grid. Drag the brush (or tap adjacent cells) to extend a
single continuous path orthogonally through every open cell exactly once. Wall cells (dark,
hatched) block the path. Drag back over the trail, tap a painted cell, or press Undo to
backtrack; Restart clears the path. The level is complete when every open cell is painted.

## Inspiration

The genre/ad format "draw one line to fill every tile". Only the general mechanic (a
Hamiltonian-path puzzle, a long-standing public-domain idea) is used; all art, naming, UI
and look are original (see `ORIGINALITY.md`).

## Level plan

24 levels, grids rising from 3x3 to 7x7. The first four levels are fully open; later levels
add walls (up to about 22% of cells). Levels are generated by construction at load time from
a seeded PRNG (`src/levels.ts`): a random self-avoiding path is carved and every unused cell
becomes a wall, so each level has a known solution. `src/logic.test.ts` additionally solves
every level with an independent DFS solver.

## Structure

- `src/logic.ts`: pure state, moves (extend/backtrack), undo, win detection, DFS solver.
- `src/levels.ts`: seeded level generation.
- `src/index.ts`: canvas rendering, pointer input, HUD, overlay, persistence.

Progress (`{ currentLevel, bestLevel }`) is stored through `ctx.storage` under `progress`;
`ctx.events.levelComplete(n)` fires once per completed level.
